# 机械设计

本目录用于保存车架、连杆机构、布局图和验证记录。现阶段重点是**做出车架并验证结构与布局**。六轮火星车式多轮连杆是候选方向，轮径、铰点、左右联动、驱动和转向方式仍待确定。

## 当前验证重点

1. **收纳与运动：**核对所有车轮、连杆和外露件的收纳外包尺寸；检查铰接运动范围、部件干涉及展开后的极限位置。
2. **障碍适应：**分析 80 mm 台阶的前轮接触、托底和下台阶稳定性；核对 45° 坡道的附着、重心与驱动条件；检查起伏路上的接地和车底净空。理论分析不能代替实物测试。
3. **通道余量：**台阶和坡道入口标称宽 450 mm。若按场地道具 ±5% 的不利情形估算，可用宽度为 427.5 mm；这是工程校核值，不是新增规则。
4. **电控布局：**为电池、主控、驱动器、接收机和线束预留安装与检修空间，特别检查活动关节处的走线余量和防夹位置。

## 建议记录的内容

- 可编辑的 CAD 源文件及其软件版本；关键尺寸图或截图。
- 每次结构调整的目的、前后差异与尚未解决的问题。
- 实物或模型验证的条件、照片/视频链接、测量数据与结论。结论注明“已验证”或“待验证”。

最终轮组、电机和采购方案应在结构与障碍校核完成后确定。
