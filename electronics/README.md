# 电控设计

本目录记录遥控、供电、驱动、控制与线束的设计依据和验证结果。团队已有**遥控器、电池等部分零部件**，但具体型号、数量、规格和可用状态尚待统一确认，不应据此提前锁定接口或采购方案。

## 当前状态

- 主控大概率从 **STM32F103** 与 **ESP32-S3** 中选择，尚未定型。
- 驱动通道数、电机参数和电源架构需要依据最终轮组与车架布局确定。
- 当前先明确接口和安装空间；原理图、PCB 与完整采购清单留待方案确认后展开。

## 必须考虑的接口

| 模块 | 需要确认的内容 |
| --- | --- |
| 遥控 | 现有遥控器及接收机的型号、通信方式、通道数与失联处理。 |
| 电池与供电 | 电池规格、固定方式、总开关、各电压需求，以及全车工作电压不超过 **30 V** 的校核。 |
| 驱动 | 电机数量、额定与堵转电流、驱动器通道和接插件；以机械方案为输入。 |
| 安装与线束 | 控制板、电源模块和电池的空间；活动连杆处的线束长度、固定、防磨和防夹。 |

计划使用的材料类别包括遥控器/接收机、电池、主控、驱动器、所需降压模块、开关、连接器及线束；**这不是已确认的采购清单**。购买配件前，先按团队约定确认商家能否开具发票。
