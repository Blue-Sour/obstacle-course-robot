# 资料与验证记录

本目录用于集中保存比赛资料、设计依据和测试结论。当前仓库**尚未收录完整官方规则或 3D 模型**；在取得并核对版本之前，不应把场地渲染图当作尺寸工程图。

## 资料分类

| 类别 | 记录方式 |
| --- | --- |
| 官方明确 | 记录规则版本、发布日期、官方链接或文件来源，并引用具体条款；原件仅在允许公开时上传。 |
| 工程推算 | 写清输入、公式、假设与误差范围；标明“推算”，不要写成官方规定。 |
| 结构参考 | 去年参赛车照片、网络视频和开源项目仅用于启发，不作为通过本届障碍的证据；优先提供来源链接。 |
| 验证结果 | 记录测试对象、场地条件、测量值、视频/照片链接、结果和复现方式。 |

后续可在本目录补充规则摘要、官方模型链接、结构与电控验证记录。新增结论应优先链接到相应 Issue 或 Pull Request，方便队员追踪其来源。
