# 机器人越障比赛项目

本仓库记录团队自主设计遥控越障机器人的需求分析、机械与电控设计、代码和验证结果。当前处于**方案验证阶段**：六轮火星车式连杆车架是正在研究的候选结构，尚未确定为最终方案，也尚未证明能通过全部障碍。

## 已知比赛边界

以下根据团队目前掌握的规则摘录整理；完整要求和场地细节以主办方最终规则、官方模型及现场测量为准。

| 项目 | 已知要求 |
| --- | --- |
| 比赛方式 | 遥控，限时 5 分钟；按检查点顺序通过，得分优先，同分比较时间。 |
| 初始状态 | 收纳尺寸不超过 **400 × 400 × 300 mm**；启动时水平投影须在 400 × 400 mm 框内，最高点须低于 300 mm。 |
| 伸展状态 | 完全离开启动区后方可展开；最大尺寸 **1000 × 1000 × 1000 mm**。 |
| 主要障碍 | 80 mm 垂直台阶、45° 且升高 80 mm 的坡道、600 mm 长的正弦起伏路段；台阶和坡道入口宽 450 mm。 |
| 电气与安全 | 全车工作电压不超过 **30 V**；电池须可靠固定。 |

场地为手工搭建，除特殊标注外道具尺寸允许 ±5% 误差。渲染图仅用于辨认地形，不能作为精确尺寸图。

## 当前状态与目录

- [机械设计](mechanical/README.md)：先完成车架，并验证机构运动、收纳尺寸和电控安装布局。
- [电控设计](electronics/README.md)：整理已有物料、主控候选、供电与机械接口；具体器件尚未定型。
- [资料与验证记录](docs/README.md)：区分规则原文、工程推算、外部参考和实测结果。

代码目录将在控制方案和硬件接口明确后建立。目录中的 README 用于说明现状和记录方法，不代表设计已验收。

## 协作方式

任务、问题和进展记录在 [Issues](https://github.com/Blue-Sour/-/issues)；需要修改文件时使用独立分支和 [Pull Request](https://github.com/Blue-Sour/-/pulls)，在描述中附对应 Issue 和验证结果。Projects 看板建立后在此补充链接。尚未确认的尺寸、选型和结论请标记为**待确认**，避免把参考资料写成比赛规则。
